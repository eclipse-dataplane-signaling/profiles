Data Plane Signaling Profiles

A collection of profiles for the Data Plane Signaling specification, defining interoperable transfer and authorization behaviours that data planes may implement.

Status of this document

This is a working draft of the Data Plane Signaling Profiles specification and is subject to change. All changes made to the specification can be reviewed in the GitHub repository. This specification is affiliated with the Eclipse Dataspace Working Group.
