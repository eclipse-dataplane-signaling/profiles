# Data Plane Signaling Profiles

A collection of profiles for the [Data Plane Signaling](https://eclipse-dataplane-signaling.github.io/dataplane-signaling)
specification, defining interoperable transfer and authorization behaviours that data planes may implement.

Public specification:
- https://eclipse-dataplane-signaling.github.io/profiles

See [WEBSITE.md](./WEBSITE.md) for authoring conventions and how to preview the spec locally.
