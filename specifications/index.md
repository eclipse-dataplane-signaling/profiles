## Introduction

This document will host the profiles for the [[[dps-base]]] specification.

Profiles define interoperable behaviours — such as transfer protocols and authorization mechanisms — that
a data plane may implement on top of the base signaling protocol. Separating them from the base
specification lets a dataspace reference a profile as the foundation for a Dataspace Protocol profile without
mandating adoption of Data Plane Signaling itself.

> This is a placeholder. The profile content — the HTTP Transfer Profile, the Token Renewal profile, and the
> Authorization Profiles and Transfer Profile Registry sections — will be migrated here from the base Data Plane
> Signaling specification as part of
> [issue #120](https://github.com/eclipse-dataplane-signaling/dataplane-signaling/issues/120).
